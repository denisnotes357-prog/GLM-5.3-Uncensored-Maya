# GLM-5.3 без цензуры на Maya

**Полная GLM-5.3 (753 млрд параметров) без отказов, 43–57 токенов в секунду на семи видеокартах, контекст 512K.**

Это форк [Project Maya](https://github.com/mw00/project-maya) (MIT) — движка, который запускает GLM-5.3-*Flash* на своих видеокартах. Maya умела только Flash. Здесь движок перенесён на **полную GLM-5.3** (`glm-dsa`: внимание MLA с RoPE, индексер DSA по токенам, 78 слоёв + NextN), для неё собран калиброванный квант 2–3 бита, а отказы сняты в два шага: веса донора и вектор отказов на лету.

[English](README.md) · [Как это сделано](docs/HOW-IT-WAS-MADE.md) · [Порт движка](docs/GLM53-ENGINE-PORT.md) · [README оригинального Project Maya](README.project-maya.md)

## Результат

| | Стоковая GLM-5.3 (наш квант) | **GLM-5.3 без цензуры** |
| --- | ---: | ---: |
| Отказы на 40 запросах JailbreakBench | 39 из 40 | **2 из 40** |
| Скорость, английский | 55–57 ток/с | **54 ток/с** |
| Скорость, русский | 45 ток/с | **43–45 ток/с** |
| Контекст | 256K | **512K** (1M работает, ~30 ток/с) |
| Размер | 267 ГБ | 267 ГБ GGUF + 2,8 ГБ pack |
| Точность против FP8-оригинала (KL, 8 текстов) | 0,204 (главный токен совпадает в 88,4%) | те же веса, кроме 155 тензоров донора |

Железо: 5× RTX 4090 48 ГБ + 2× A100 40 ГБ (320 ГБ видеопамяти), 503 ГБ RAM. Все эксперты в видеопамяти, с диска при генерации ничего не читается.

Как росла скорость: 14,5 ток/с (первая рабочая сборка, крупный квант) → 20 (MTP) → 38,6 (меньший калиброванный квант) → **45–57 (окно MTP на конвейере карт)**. Без MTP — 24 ток/с.

## Что внутри

- **Порт движка на `glm-dsa`** — внутри родного `Glm5Model` Maya на флагах архитектуры: Flash работает как раньше, а GLM-5.3 получает всё, что уже было в Maya, — уровни экспертов VRAM/RAM/диск, разбиение слоёв по картам, многотокенное предсказание, пакетный промпт, KV-стриминг, сервер с OpenAI/Anthropic API и чат в браузере.
- **Окно MTP на конвейере** (`STRATA_GLM_MTP_PIPE=1`): голова NextN предлагает цепочку до 7 токенов, цепочка проверяется окном, проходящим все семь карт. Ответ токен в токен как у обычного декода; скорость ~32 → 45–57 ток/с.
- **Вектор отказов на лету** (`src/core/glm_ablate.cuh`): три направления на слой вычитаются из остаточного потока после каждого слоя. Без переквантования — выключается и регулируется в конфиге.
- **Инструменты кванта** (`tools/glm53/`): калибровка по FP8, imatrix + GPTQ для экспертов, рецепты, вставка донора (`make_gm24u.py`), съём вектора (`tools/glm53/ablate/`).
- **Тесты**: синтетическая GLM-5.3 из 6 слоёв против `transformers`, сверка медленного и быстрого путей.

## Исправления 20.10.2026 (обновитесь, если клонировали раньше)

- **Агентные сессии могли превращаться в мусор.** Если новый разговор одного клиента обрывался посреди чтения промпта, движок уже сбросил кэши, но оставлял запись о снимке прежнего разговора; следующий ход того разговора мог продолжиться поверх сброшенного состояния и выдать бессмыслицу. Теперь сброс аннулирует снимок (найдено и доказано на соседнем порте MiMo-V2.6-Pro, где этот же путь ломал агентов).
- **Штрафы за повторы работают.** `presence_penalty`, `frequency_penalty` и `repetition_penalty` в пути GLM молча игнорировались; запрос с ними теперь идёт пошаговым путём с историей (медленнее: без черновиков MTP для этого запроса).
- Сервер убирает лишние теги размышлений из истории, которую агенты присылают обратно.

## Быстрый старт

```bash
git clone https://github.com/denisnotes357-prog/GLM-5.3-Uncensored-Maya
cd GLM-5.3-Uncensored-Maya
./setup.sh          # как у Maya: .venv, ggml, сборка build/strata; на предложение скачать модель ответить «нет»
pip install -U huggingface_hub
hf download nofacedfl/GLM-5.3-Uncensored-Maya --local-dir models/GLM-5.3-Uncensored-Maya
tools/glm53/run-glm53.sh                                       # без цензуры: донор + вектор
tools/glm53/run-glm53.sh configs/glm53-uncensored-novector.json  # только донор
```

- Чат: http://127.0.0.1:8095/ · OpenAI API: `/v1/chat/completions`, модель `glm-5.3` · Anthropic API: `/v1/messages`
- Размышления: `reasoning_effort` = `none` / `low` / `high` (по умолчанию) / `max`
- Загрузка ~3 минуты. В логе сервера должна быть строка `glm ablate: 1437696 values from tools/glm53/ablate/dir3.f32 ... scale 1.00`.

Конфиг рассчитан на 7 карт и ~320 ГБ видеопамяти; что в нём менять под свои карты — в [README](README.md#fitting-your-gpus).

## Как сняты отказы

1. **Донор.** [`dealignai/GLM-5.3-UNCENSORED-FP8`](https://huggingface.co/dealignai/GLM-5.3-UNCENSORED-FP8) (MIT) отличается от оригинала только `self_attn.o_proj` и `mlp.shared_experts.down_proj` — 155 тензоров, 8,9 ГБ. Скачали только их, сжали в те же типы и вставили в наш квант. Отказы 39 → 6 из 40.
2. **Вектор.** Для оставшихся — три направления на слой (без размышлений / открытое размышление / конец собственного размышления модели), снятые на 256 вредных и 100 безвредных запросах и вычитаемые из остаточного потока на лету. Отказы 6 → 2 из 40. Методика и исходный хук в движке — [alesha-pro](https://github.com/alesha-pro/project-maya/blob/glm-ablate/docs/GLM-ABLATE.md) (для Flash); здесь вектор снят заново для полной модели.

Подробно, с цифрами и тупиками: [docs/HOW-IT-WAS-MADE.md](docs/HOW-IT-WAS-MADE.md).
